# 2026-10-27 캡처 미리보기와 문서 처리 개선

본문 Ctrl+V로 캡처를 즉시 첨부하고 화면에 사진을 표시한다. 클릭·Enter로 큰 미리보기, Esc로 닫기, 원본 다운로드를 지원한다. 긴 글과 이전 사진의 지연 로딩 뒤에도 새 캡처를 확인할 수 있다. 기존 일반 이미지 첨부에도 편집·읽기 미리보기를 제공한다.

PDF를 포함해 파일 가져오기 전에 펼쳐 보기와 슬라이드 보기를 선택한다. 페이지 삭제는 DB 저장 후 해당 페이지 화면만 갱신하며 연결 폴더 동기화는 백그라운드에서 이어진다. 폴더 소유권·외부 수정·공유 첨부 보호와 삭제 복원을 유지한다.

오늘부터 쓰는 방법

  1. 새 기록을 누르고 제목과 내용을 적습니다. 쓰는 동안 자동 저장됩니다.
  2. 편집 중 /를 입력하면 제목·목록·표 같은 명령을 고를 수 있습니다. 사진·녹음·받아쓰기는 본문 위 도구줄에 있습니다.
  3. 설정 · 백업에서 자료를 가져오거나 백업합니다. 가져온 원본은 그대로 보관합니다.
  4. 지식맵에서 기록 사이의 관계를 2D·3D 지도로 확인합니다. 영역·기록 수·고르는 기준을 바꾸고, 선을 누르면 연결 이유가 나옵니다.

기존 PC 기록 옮기기

  1. 기존 서재에서 설정 · 백업 → 첨부를 포함한 백업 내보내기를 누릅니다.
  2. 이 온라인 앱에서 설정 · 백업 → 백업 파일 가져오기를 누릅니다.
  3. 내려받은 .pkem 파일을 선택하고 내용을 확인한 뒤 가져옵니다.

웹주소가 다르면 브라우저의 저장 공간도 다릅니다. 구글 동기화를 설정하기 전에는 기존 기록이 다른 기기로 자동 이동하지 않습니다. 사용 중인 서재의 최신 백업을 보관하세요.

자료는 어디에 보관되나요?

개인 기록과 첨부는 지금 쓰는 기기의 브라우저에 저장됩니다. 이 주소에는 기록을 받아 두는 서버가 없습니다. 브라우저 데이터를 지우기 전에 백업하세요.

DOCX·PPTX·HWPX·XLSX·PDF의 본문 추출은 브라우저에서 처리합니다. 서식과 이미지 지원 범위는 원본과 다를 수 있습니다. 스캔 OCR은 첨부의 문자 인식 버튼을 사용합니다. 옛 HWP·XLS는 별도 변환 도구가 필요합니다.

녹음·사진은 브라우저 권한이 필요합니다. 받아쓰기는 지원 브라우저에서만 동작하며, 동의한 경우 브라우저의 음성 서비스가 이용될 수 있습니다. PC 폴더 연결과 자료 카드 파일 자동 반영은 PC의 크롬·엣지에서 사용하며 앱이 열려 있을 때 확인합니다.

새 기능: 블록·데이터베이스·OCR·음성·의미 검색

  1. 기록 편집 도구줄의 블록으로 편집에서 문단을 나누어 쓰고 순서를 옮깁니다. 기존 Markdown을 그대로 보존합니다.
  2. 왼쪽 새 데이터베이스에서 속성·행을 추가합니다. 표·보드·달력·목록·갤러리·날짜 순 보기, 필터·정렬, CSV 가져오기와 저장을 쓸 수 있습니다. 수식은 [수량] * [단가]처럼 사칙연산을 쓰고, 연결 개수 속성으로 연결한 기록 수를 셉니다.
  3. 이미지나 스캔 PDF를 첨부하고 스캔 문자 인식을 누릅니다. PDF는 한 번에 최대 50쪽을 선택합니다. 인식 결과를 고친 뒤 원본에 연결된 새 기록으로 저장합니다.
  4. 음성 첨부의 음성 파일 전사를 누릅니다. 설정에서 자동 시작을 켤 수 있습니다. 최대 30분의 음성을 기기에서 처리하며 처음에는 모델 다운로드가 필요합니다. 한국어·영어·일본어를 선택할 수 있고 오인식은 저장 전에 수정합니다.
  5. 왼쪽 AI 의미로 찾기에 찾고 싶은 내용을 적습니다. 다국어 문장 모델을 최초 다운로드하고 색인을 만든 뒤 표현이 비슷한 기록을 찾습니다. 결과의 유사도는 정확도나 확률이 아닙니다.
  6. 설정의 PC · 휴대폰 구글 동기화에서 같은 계정을 연결합니다. 공개 OAuth 클라이언트 ID를 먼저 준비해야 합니다. 구글 연결 설정 안내
  7. 옛 .ppt는 구글 연결 후 구글로 변환하여 미리보기를 누릅니다. 파일을 내 드라이브로 보내 Google Slides와 PDF로 바꾸며, 변환용 Slides는 휴지통으로 옮깁니다. PDF 결과는 기기에 남아 다음에는 다시 전송하지 않습니다.

현재 범위: 앱 종료 후 동기화·영구 로그인, Notion 전체 블록·수식·집계·협업·자동화와 동일한 기능은 아직 없습니다. 동기화는 로그인 후 앱을 열고 편집을 마쳤을 때 동작합니다. 실제 구글 계정 연결과 옛 PPT 변환은 계정 설정 후 검증해야 합니다.

데이터베이스 구조·내용은 .pkem 백업에 포함되며 Markdown ZIP에도 JSON 사본이 들어갑니다. PDF 설명서는 기존 기본 사용법이며, 이 절이 확장 기능의 최신 안내입니다.

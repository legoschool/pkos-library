내 구글 드라이브로 기기 연결하기

기록장은 로그인 없이도 기기에 저장됩니다. 구글 동기화와 옛 PPT 변환에는 앱을 식별하는 Google OAuth 웹 클라이언트 ID가 필요합니다. 비밀번호나 API 비밀 키를 기록장에 넣지 않습니다.

  1. Google Cloud Console에서 프로젝트를 선택하거나 만듭니다.
  2. Google Drive API를 사용 설정합니다.
  3. Google Auth Platform에서 앱 이름과 동의 화면을 설정합니다. 테스트 상태라면 사용할 계정을 테스트 사용자로 추가합니다.
  4. 클라이언트 유형을 웹 애플리케이션으로 선택합니다. 승인된 JavaScript 원본에 https://legoschool.github.io와 https://pkos-library.vercel.app를 추가합니다. 경로·끝 슬래시는 넣지 않습니다.
  5. 공개 클라이언트 ID(…apps.googleusercontent.com)를 각 기기의 기록장 → 설정 → PC · 휴대폰 구글 동기화에 넣고 같은 계정을 연결합니다.

동기화 파일은 내 드라이브의 앱 전용 숨김 공간에 저장됩니다. Drive의 앱 연결 관리에서 앱 데이터를 삭제하면 클라우드 사본이 사라집니다. 별도의 .pkem 백업을 유지하세요.

동작 범위

  • 앱이 열린 동안 저장 후와 1분마다 양방향으로 합칩니다. 오프라인 작업은 다시 연결했을 때 반영됩니다.
  • 같은 기록을 양쪽에서 수정하면 한 버전은 충돌 사본으로 보관합니다.
  • 로그인은 새로고침·재실행·토큰 만료 때 다시 연결해야 합니다. 앱 종료 후 자동 동기화와 지속 로그인용 서버는 아직 제공하지 않습니다.
  • 동기화 자료는 기기당 75MB, 합친 파일은 80MB까지입니다. 대규모 첨부는 원본 드라이브 링크로 관리하세요.
  • 옛 PPT는 사용자가 변환 버튼을 누를 때 내 드라이브로 전송해 Google Slides → PDF로 바꿉니다. 글꼴이나 일부 배치는 달라질 수 있습니다.
  • 구글 OAuth를 공개 앱으로 배포할 때는 Google의 공개·검증 요건을 별도로 충족해야 합니다.
